# AI 员工工作台 · 全面重做方案 v12（高级面板）

> 用户决策：放弃像素场景（v11 场景太丑）。全面重做为**高级面板**——现代精致、数据可视化、交互丰富，完整呈现 AI 员工认知架构（灵魂/记忆/进化/思维/技能/习惯/任务/对话）。

---

## 一、设计基调

- **视觉**：现代高级面板（暗色 + 浅色双主题，非像素场景）。精致卡片、清晰层级、数据图表、状态色语义化。硬边到微圆角过渡，克制的玻璃拟态/投影，无像素风。
- **信息架构**：围绕"一个 AI 员工 = 完整认知体"组织——不是聊天框，不是看板，而是**员工工作台**（像 Notion 人物页 + 数据仪表盘 + 对话助手融合）。
- **交互**：Tab 分区、实时数据、图表（成长曲线/任务分布）、状态徽章、快捷操作、键盘可达。

## 三、员工头部卡（主面板顶部）

- **头像**（角色图标/emoji 圆角卡）+ **名字 + 角色**（如 守夜人 · 服务器运维监控员）
- **状态徽章**：在岗/忙碌/休息（绿/黄/灰点 + 文字）
- **等级 + 成长条**（Lv.3 + 经验进度条）
- **工作区路径**（chip）+ **模型**（chip）
- 右上：操作按钮（对话 / 暂停 / 派发一次 / 删除）

## 四、7 Tab 信息面板（主面板主体）

| Tab | 内容 | 呈现 |
|---|---|---|
| 📅 经历 | 任务时间线（timeline） | 纵向时间线：每次任务/指令/结果，时间戳+状态色 |
| 🧰 技能 | 技能列表（skills） | 技能卡：名称/关键词 chips/熟练度条 |
| 🕐 习惯 | 习惯（habits） | 习惯列表：名称/值（frequency） |
| 🧠 思维 | 思维留痕（thinking） | 任务选择器 + 思维链时间线（plan/decision/tool/reflect 彩色标识） |
| 💬 通讯 | 对话记录（chat） | 消息气泡流（用户/员工） |
| 📊 状态 | 运行状态 | 指标网格：任务数/成功率/Token/队列/Agent 存活 + 状态点 |
| 🌱 成长 | 成长轨迹 | 成长曲线图（成功率趋势）+ 统计卡（任务/成功率/技能/经验/在岗天数）+ 进化记录 |

- Tab 数据来自后端真实端点（growth/thinking/chat/status 已有）。
- 空态引导：每个 tab 无数据时给"如何产生数据"提示。

## 五、右操作区（ACTION 320）

- **对话区**（上）：指令输入 + 消息流（气泡：用户右/员工左，员工头像+名字）
- **快捷操作**（下）：选择工作区（弹窗/列表）/ 派发一次 / 暂停恢复 / 删除员工（确认）

## 六、左导航（NAV 220）

- **logo + 标题**（AI 员工）
- **员工列表**：头像/名字/角色/状态点（在岗绿/离线灰）+ 选中高亮
- **+ 创建员工**（打开向导：任务→AI 生成灵魂→工作区→创建）
- **☀/🌙 主题切换**（底部）

## 七、视觉规范

- **暗色主题**：底 #0f141c / 面板 #161d29 / 边框 rgba(148,163,184,.14) / 强调青 #38bdf8 / 文字 #e2e8f0
- **浅色主题**：底 #f4f6f9 / 面板 #fff / 边框 rgba(15,23,42,.1) / 强调蓝 #2563eb / 文字 #1e293b
- 字体：Inter/系统无衬线（面板感，非像素）
- 圆角 8-12px、卡片阴影克制、状态色语义（绿/黄/红）
- 数据图表：成长曲线（SVG 折线）、指标网格

## 八、交互细节

- Tab 切换动画（内容淡入）
- 状态点实时（5s 轮询 status）
- 对话发送 → 乐观更新 + 员工回复流
- 创建向导步骤条（任务→灵魂卡→工作区→就位）
- 成长曲线 hover 显示数据点
- 删除员工二次确认

## 九、实现优先级

1. 三栏骨架 + 双主题（暗/浅）+ 员工列表 + 头部卡
2. 7 Tab（数据接后端：growth/thinking/chat/status）
3. 右对话区 + 快捷操作
4. 创建向导（任务→AI 灵魂→工作区→创建）
5. 图表（成长曲线）+ 动画打磨
